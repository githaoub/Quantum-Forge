# Quantum Forge

A Roblox incremental built around a forge you strike, a crate you roll, and a
blade you chase. UI-first: the screen is the app, and every panel is drawn in
Luau through `UiKit` rather than composed in Studio.

## Layout

| path | what lives there |
| --- | --- |
| `src/shared` | config, registries and the network contract. Every price and table. |
| `src/server` | authority: progression, forge physics, economy, saves, trade, boards. |
| `src/client` | the whole UI. `Theme` + `UiKit` first, then one module per surface. |
| `assets/` | source art: badges, blade meshes, currency, crate references. |
| `scripts/` | Python asset pipeline (upload, prep, contact sheets). |
| `user-manual/` | art prompt sets for external generators. |
| `incremental/` | the design record. Junctioned into the Obsidian vault as `quantum-forge`. |

## Running it

```
rojo serve                    # sync into Studio
selene src/                   # static pass, expected 0/0/0
rojo build -o verify.rbxlx    # produce a place file
```

`verify.rbxlx` is a build artifact and is ignored. `assets/generated/` is
regenerated by `scripts/`, also ignored.

## The design record

`design-decisions.md` is append-only: every ADR keeps its number. Build logs are
per pass and measured, not narrated. The module map is `code-map.md`. The text-first
research pass, with its audit, is `game-design-research.md`. All of them live in
`incremental/`, which appears in the vault as `quantum-forge`.
